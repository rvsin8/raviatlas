# raviatlas

RxAtlas is an interactive anatomy and pharmacology atlas connecting body regions, conditions, and treatments.

## Live site

GitHub Pages: https://rvsin8.github.io/raviatlas/

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The `main` branch deploys automatically to GitHub Pages through GitHub Actions.

> Educational use only. Not medical advice.
